A token launch radar: it reads a sealed DefiLlama snapshot, ranks the protocols that record no token by an implied value computed from their own figures (TVL, seven-day growth, how long they have run with no token, and how many chains they run on), and gives every protocol a seven-step farm plan with costs and times. The board covers the whole watchlist floor and adds the early pre-token protocols below it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
